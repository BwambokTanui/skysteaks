# SkySteaks

Sportsbook and Aviator at [skysteaks.com](https://skysteaks.com). Play credits across football, basketball, tennis, and crash rounds.

## Setup

1. Copy `.env.example` to `.env.local` (or use the saved SkySteaks Supabase project).
2. Run `supabase/schema.sql`, then `supabase/sports.sql`.
3. `npm install && npm run dev`

Credentials for this product live outside the repo at `C:\Users\tando\.skysteaks\credentials.env`.
